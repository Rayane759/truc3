# Protocole

**Objectif** : Recueillir les irritants / besoin des des développeurs concernant en particulier leur expérience avec l'offre et l'utilisation des outils suivants:

* le CI/CD
* La configuration d'un environnement
* Le déploiement 
* Le MCO / MCS d'un environnement
* L'observabilité 

Afin de garantir un capture d'information la plus large possible, On va le faire par le biais de 3 méthodes:

- Interviews
- Focus Groups
- Sondage

## Interviews

**Objectif**: Obtenir une compréhension initial du problème et du contexte. Notamment:

* pratiques des utilisateurs
* besoins et attentes
* experience personnelles
* difficultés rencontrées

!!!info "Décision"

    Les protos personnas suivants seront prioritaire au sein de chaque SNDI:

    - Dev Junior
    - Dev applicatif fullstack
    - Dev DevOps

    On ciblera 2 personnes par SNDI (un dev Junior + un dev applicatif) (soit 8 personnes) + 1 personnes dans un seul des SNDI qui a le profil DevOps.

## Focus Groupe

### Simulation de delivery

Des ateliers de type *focus group* ont été organisés au sein de chaque SNDI afin d’observer concrètement les pratiques de delivery.

Le dispositif reposait sur une simulation dans laquelle les équipes devaient livrer une fonctionnalité :
- une première fois dans leur contexte actuel
- une seconde fois avec des capacités de plateforme

Lors de la première phase, des événements perturbateurs ont été introduits afin de refléter les difficultés réelles (dépendances, instabilité des outils, complexité des environnements).

La seconde phase permettait aux équipes de sélectionner certaines capacités de plateforme (CI/CD standardisé, self-service infrastructure, observabilité, etc.) et d’en mesurer l’impact.

👉 Cette approche a permis de :

- mettre en évidence les principaux irritants du cycle de delivery
- objectiver les dépendances techniques et organisationnelles
- identifier les capacités de plateforme perçues comme prioritaires

Les résultats présentés dans ce rapport s’appuient sur la synthèse de ces ateliers. Le CR de chacun des focus groupes est disponible [ici](./../annexes/annexe-3A-focus-groupe-sndil.md)
