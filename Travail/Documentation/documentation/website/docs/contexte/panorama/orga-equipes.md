# Organisation des équipes (produit, dev, ops, sécu, data, etc.)

L’organisation actuelle est structurée autour de trois grands types d’équipes :

- Équipes de développement (Dev) :
 
  - **Fonctionnement** : Ensemble de développeur responsables d’un produit ou d’un périmètre fonctionnel spécifique.
  - **Objectif** : Elles assurent le développement, la maintenance et l’évolution des applications.
  - Rendement : elles rendent compte directement à leurs équipes métiers.

- Équipes Opérations (Ops) :
    
  -  **Fonctionnement** : Réparties en équipes “services”, chacune fournissant des services ou des plateformes aux équipes Dev.
  -  **Objectif** : fournir des outils pour faire fonctionner les applications et l'infrastructure Insee. Les Ops doivent fournir des solutions techniques pour répondre aux besoins des développeurs. 
  - **Dépendances** : les équipes Dev peuvent solliciter ces services pour déployer ou gérer leurs applications, ce qui peut créer des goulots d’étranglement en cas de forte demande.

- Équipes transverses :
    
  - **Fonctionnement** : Interviennent ponctuellement au cours du cycle de vie des projets pour de l'expertise / conseils / audits de sécurité
  - **Objectifs** : Leur rôle est de définir des standards, guider les choix techniques et garantir la conformité, tout en restant disponibles pour les équipes Dev et Ops.
  - **Qui** : Incluent architectes et sécurité.
